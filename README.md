# OpenHealth

En privat allt-i-ett hälsoapp för Android. Garmin-klocka, kroppsvåg (Huawei CH100) och fasta i en och samma app. All data stannar i telefonen: inget konto, inget moln, ingen spårning.

## Tack till
OpenHealth bygger på arbetet från:
- [Gadgetbridge](https://codeberg.org/Freeyourgadget/Gadgetbridge) och alla dess bidragsgivare
- [Pulse](https://github.com/zoop-dev/pulse) av zoop (utgångspunkt, commit `4ef13c310cbc5b1879d10f55a758df4058683fc7`)
- [openScale](https://github.com/oliexdev/openScale) (vågstöd, kommer)
